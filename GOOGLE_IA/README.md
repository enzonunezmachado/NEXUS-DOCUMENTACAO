# GOOGLE_IA — Documentação técnica do NEXUS

Esta pasta é o espelho documental da engenharia produzida e mantida pelo ambiente Google AI Studio no repositório ativo Projeto Nexus.

## Fonte e precedência

1. Código do repositório ativo: fonte de verdade da implementação real.
2. Markdown versionado em `docs/` no repositório ativo: documentação técnica oficial.
3. Arquivos desta pasta: cópia de continuidade e consulta no repositório Nexus Documentação.
4. Artefatos internos do AI Studio, especialmente `NEXUS_CONTINUIDADE`: memória operacional complementar, nunca fonte única.

## Sincronização

A sincronização deve comparar os documentos de origem com os arquivos existentes aqui, preservar histórico, atualizar o conteúdo vigente e registrar origem/data. Não copiar cegamente nem eliminar registros históricos.
